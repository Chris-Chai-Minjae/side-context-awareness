## 판정과 한계

**S-1 불합격.** 계획된 캡처당 `aside repl` 실행은 100회 동안 세션 항목 100개 증가를 동반했다. ADR-011에 따라 Aside DOM 어댑터는 기본 off가 적합하며, 정본 `00-decisions.md`의 최종 기록은 상위 담당자가 수행한다.

포커스 이탈 1회는 감지했지만 다른 작업 또는 Orca UI의 간섭 여부를 이 기록만으로 구분할 수 없다. 실행 전 별도 조회값 631과 실행 시작값 633 사이에도 세션 항목이 2개 늘었고, 본 실행 직후값 733과 대조 관찰 시작값 734 사이에도 1개 늘어 공유 환경의 외부 활동 가능성이 있다. 따라서 새 세션 100개의 개별 원인을 단정하지 않는다. 탭 메타데이터는 안정적이었으나 브라우저 크롬의 일시적 디버그 표식은 직접 시각 확인하지 않았다. 이 한계와 관계없이 세션 증가만으로 합격 기준을 충족하지 못한다.
