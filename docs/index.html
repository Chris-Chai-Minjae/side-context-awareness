내일 다시 찾다.

Side는 브라우저와 Mac 앱의 활동을 내 기기에 기록하고, 하루의 요약과 출처를 다시 찾게 해줍니다. 검색은 에이전트에서도 이어집니다.

어떻게 작동하나요

기록하고, 요약하고, 출처로 돌아갑니다.

Side는 읽을 수 있는 활성 창의 맥락을 모으고, 허용한 요약 제공자로 하루를 정리합니다.

01 / CAPTURE

내 Mac에서 관찰

허용한 권한으로 활성 앱과 브라우저의 텍스트를 읽습니다. 특정 앱·웹사이트는 제외하고 언제든 일시정지할 수 있습니다.

02 / REMEMBER

시간과 주제로 정리

로컬 기록을 검색하고, 요약 제공자를 설정해 날짜별 기억을 만듭니다. 요약은 제공자 설정과 전송 동의가 있어야 생성됩니다.

03 / RECALL

에이전트에서 다시 찾기

MCP를 연결하면 history_search, history_read, memory_search로 질문하고 출처를 확인할 수 있습니다.

시작하기

소스에서 직접 빌드하세요.

macOS 14+, Bun, Xcode Command Line Tools, FTS5와 확장 로딩을 지원하는 SQLite dylib가 필요합니다. 빌드 과정에서 MiniLM 모델을 내려받습니다.

처음 쓰는 사람을 위한 자세한 안내 ↗

git clone https://github.com/Chris-Chai-Minjae/side-context-awareness.git
cd side-context-awareness
bun install --frozen-lockfile
bun run build
mkdir -p "$HOME/Applications"
ditto apps/side-mac/.build/release/Side.app "$HOME/Applications/Side.app"
open "$HOME/Applications/Side.app"

앱을 종료한 뒤 새 빌드를 복사하세요. 이 로컬 빌드는 임시 서명되며, 교체 후 macOS 권한을 다시 부여해야 할 수 있습니다. 상세 조건은 README를 확인하세요.

모델과 에이전트

연결은 각자 선택합니다.

MiMo, MiniMax, OpenAI API 키는 각 사용자가 Side 설정에 직접 입력하며 macOS Keychain에 보관됩니다. 이미 로그인한 Claude Code를 요약 제공자로 선택할 수도 있습니다.

요약 제공자

모델 설정은 선택 사항입니다. 설정하지 않아도 캡처할 수 있지만 요약은 대기합니다.

MCP 연결

Claude Code, Codex, Cursor, Aside 등은 각 클라이언트에서 Side의 로컬 MCP 서버를 등록해야 합니다.

claude mcp add --scope user side -- "$HOME/Applications/Side.app/Contents/Resources/side" mcp

Side가 실행 중일 때 Claude Code 사용자 범위에 등록하는 예입니다. 다른 에이전트 명령은 연결 문서 ↗를 참고하세요.

프라이버시와 동의

기록과 전송 범위를 직접 정합니다.

Side는 원본 캡처를 클라우드에 동기화하지 않습니다. 기록 보존 기간, 제외 목록, 일시정지, 삭제를 설정할 수 있습니다.

macOS 권한

Accessibility와 Input Monitoring을 안내합니다. Screen Recording은 OCR용 선택 권한이며, 지원 브라우저 URL에는 Automation 권한이 쓰입니다.

저장 방식

원본의 민감 컬럼은 마스킹 후 암호화하지만 모든 비밀을 탐지하지는 못합니다. 요약과 날짜별 페이지는 로컬에 평문으로 남습니다.

외부 전송

“Send evidence to this provider”는 기본적으로 꺼져 있습니다. 켜면 마스킹한 활동 브리핑이 선택한 제공자로 전송됩니다.

에이전트 결과

연결한 에이전트가 MCP 검색 결과를 자신의 모델에 전달할 수 있습니다. 사용 전 해당 서비스의 데이터 정책을 확인하세요.

현재 상태

공개 소스, 진행 중인 검증

Side는 개발 중입니다. 현재 배포 방식은 각 사용자 Mac에서 소스를 빌드하는 방식이며, 사전 빌드 앱의 Developer ID 서명·공증과 장시간 실기기 검증은 완료되지 않았습니다. Grok Build 로그인으로 Side 요약을 만드는 경로는 검증되지 않았으며 요약 제공자로 연결되어 있지 않습니다. 기능별 근거와 남은 게이트는 저장소의 QA 보고서에서 확인할 수 있습니다.

How it works

Capture, summarize, trace the source.

Side gathers readable context from the active window and organizes your day through a summary provider you authorize.

01 / CAPTURE

Observe on your Mac

With your permission, Side reads text from active apps and browsers. Exclude apps or websites, or pause capture at any time.

02 / REMEMBER

Organize by time and topic

Search local records and configure a summary provider for daily memories. Summaries require provider setup and consent to send evidence.

03 / RECALL

Ask an agent

Connect MCP to use history_search, history_read, and memory_search and inspect the source.

Get started

Build it from source.

Requires macOS 14+, Bun, Xcode Command Line Tools, and a SQLite dylib with FTS5 and extension loading. The build downloads the MiniLM model.

Detailed beginner guide (Korean) ↗

git clone https://github.com/Chris-Chai-Minjae/side-context-awareness.git
cd side-context-awareness
bun install --frozen-lockfile
bun run build
mkdir -p "$HOME/Applications"
ditto apps/side-mac/.build/release/Side.app "$HOME/Applications/Side.app"
open "$HOME/Applications/Side.app"

Quit Side before copying a new build. Local builds use ad hoc signing, so macOS permissions may need to be granted again after replacement. See the README for details.

Models and agents

Your connections, your choice.

Each user enters their own MiMo, MiniMax, or OpenAI API key in Side settings; the keys are stored in their macOS Keychain. An existing Claude Code login is an optional summary provider.

Summary provider

Provider setup is optional. Capture can run without one, but summaries will wait.

MCP connection

Register Side's local MCP server separately in Claude Code, Codex, Cursor, Aside, or another client.

claude mcp add --scope user side -- "$HOME/Applications/Side.app/Contents/Resources/side" mcp

Example: register Side in Claude Code at user scope while Side is running. See agent connection instructions ↗ for other clients.

Privacy and consent

Choose what stays and what leaves.

Side does not sync raw captures to the cloud. Set retention, exclusions, pause capture, or delete Side history.

macOS permissions

Side guides you through Accessibility and Input Monitoring. Screen Recording is optional for OCR; Automation is used for supported browser URLs.

Local storage

Sensitive raw columns are masked and encrypted, but pattern matching cannot catch every secret. Summaries and daily pages remain readable local files.

External provider

“Send evidence to this provider” is off by default. Turning it on sends masked activity briefings to your chosen provider.

Agent results

A connected agent may pass MCP results to its own model. Check that service's data policy before connecting it.

Development status

Open source, with gates still open.

Side is in development. Distribution currently means building from source on each user's Mac. A prebuilt app has not completed Developer ID signing and notarization, and long running device checks remain. Using a Grok Build login to create Side summaries is unverified and is not connected as a summary provider. See the repository's QA reports for evidence and open gates.
